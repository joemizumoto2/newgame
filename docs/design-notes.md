# 設計メモ（2026年10月の企画会話のまとめ）

最初の企画会話で決まったこと、ユーザーの反応、却下した案、次の課題。新しいセッションはこれを前提に進める。

## 1. 出発点

「発明勝ちで流行るアプリを作りたい」から始まった。参考にした流行りもの：

- **WordBlade（文字ブレード）**：入力した1文字がベーゴマ風のコマになって戦う。文字の形で強さが決まり、「どの字が最強か」の研究が起きている。https://apps.apple.com/jp/app/wordblade-%E6%96%87%E5%AD%97%E3%81%A7%E6%88%A6%E3%81%86%E3%82%B3%E3%83%9E%E3%83%90%E3%83%88%E3%83%AB/id6819836440
- **80億分の1**：AI で作った人生シミュレーション。約4時間で作られ、X でバズった
- スイカゲーム、動物タワーバトル、Infinite Craft、パワプロのサクセス

ユーザーが WordBlade を評価した理由：**既にあるフォーマット（ベイブレード）に、世界共通のもの（文字）を入れて、しかも感覚的。環境が回り、やり込みが進む。**

## 2. ユーザーが大事にしている条件

1. 器は誰でも知っている遊び。独自ルールの盤面ゲームは「敷居が高い」
2. 入力は**選ぶだけ**。手書きや撮影は「技術が要って広まりにくい」
3. **ある程度客観的だけど、なんとなく分かる**ステータス。理由が読めないと盛り上がらない
4. 題材は要素が多いもの（国は属性が多いから良い。元素や誕生日は少ない）
5. 戦いがある。盛り上がる
6. 一回で終わらない。環境が回る（三すくみ）か、育てられる
7. API 代がかからない（ルールとテンプレートで作る）
8. センシティブな題材を避ける（実在の国を戦わせない）
9. 「最強の国ができたら熱い」。ダイジョーブ博士のようなギャンブル要素が欲しい
10. 無双はつまらない

- 結末に国の呼び名（例：「砦と港の国」）と、選択のつながりの一覧
- 反応：「**結構面白かった**」
- 字体：「タイトル以外はもう少し読みやすいフォントに。太すぎて読みづらい」→ 対応済み

## 4. いま残っている一番の課題：途中の行動の選択肢が少ない

ユーザーの言葉：「途中の行動が選択肢少ないね。やることは決まってて、行動ポイントがあってそれの中でやりくりするとかなのかな、この辺むずい」

検討した案と反応：

| 案 | 内容 | 反応 |
|---|---|---|
| 行動ポイント制 | 毎ターンのポイントで複数の行動を買う | 抽象的で国らしさが薄い（未評価） |
| 手札制（デッキ構築） | 建物から新しいカードが増える | 重い（未評価） |
| 民の割り振り | 民（人手）を決まった仕事に配る。建物が増えると配り先が増える | 提案した。ユーザーはこの後カタンの話へ |
| カタン型 | サイコロ → 土地が資源を生む → 建てる → 交易 | ユーザー：「投資したものが回収されるカタンみたいなイメージでもいいかも」→ 具体化すると「まあそれだとカタンすぎる」 |
| **投資と伏線の回収をひとつにする**（最新の提案、未回答） | 下記 | ユーザーの返事待ち |

### 最新の提案：投資の回収と伏線の回収をひとつにする

1. 毎ターン、国の収入（金貨と人手）が入る。量は建てたもので決まる（サイコロなし）
2. 事業は「植える」もの。完成まで時間がかかる。同時に複数抱えられ、限られた収入をどこに回すかで悩む。追加投資で早まり、放っておくと止まる
   - 例：港（金貨3 人手2、2ターン）→ 毎ターン金貨+2・異国の縁 ／ 北の砦（金貨2 人手3、1ターン）→ 守り↑ ／ 学舎（金貨4 人手1、3ターン）→ 人が育つ・大きな伏線 ／ 収穫祭（金貨1、すぐ）→ 民心↑
3. 完成すると、収入と物語（伏線）の両方が返ってくる。「早く効く小さな投資」か「遅いけれど大きく返る投資」か、が核
4. 出来事が投資を揺らす（災害で建設が止まる、戦の前に軍資金に回すか）

カタンとの違い：収入はサイコロでなく建てたもので決まる／回収されるのは資源と物語／完成まで年数がかかる／他プレイヤーとの交易はない。

次の一手として「事業の種類、完成までの年数・費用・返ってくるものの一覧表から詰める」ことを提案している。

### v4：じっくりモードを追加（2026-10-20）

ユーザーの要望：「じっくりやるモードを追加したい。30年を1年ずつ／問いを増やす（分岐を増やす）／ランダムな出来事を増やす（プラスもマイナスも、回収されない意味のないものも）／トロフィー／過去の国を保存して見返したい（保存するかどうかは自分で決める）」

確認して決めたこと：
- じっくりモードは標準モードとは別に、タイトルで選ぶ。標準モードはそのまま残す
- 問いは12（標準は8のまま）。**各問いの選択肢を8つにし、毎回4つだけ出す**（両モード）。同じ土地や気候でも言い回しと効果が少し違う
- 1年ずつにするのに合わせて、「投資の回収と伏線の回収をひとつにする」案（植える型）をじっくりモードに入れた。ユーザー「じゃあそうしましょう。やってみて考えます」
- 小さな出来事は毎年約35%（2〜3年に1回）。選択はなく読むだけ。良い・悪い・何も起きない（珍しい雲、曲芸師など）
- **戦は確率で起きる**。選択や出来事（悪い噂、隣国の恨み、守りが手薄、国境の小競り合い…）で「戦の気配」が上がる。最後の決戦だけは必ず30年目
- 保存は「この国を残す」を押したときだけ。端末（ブラウザ）にだけ残り、端末をまたぐと見られない（了承済み）

植える型の数値（自動プレイで決めた）：
- 基本収入は毎年 金貨1・人手2。始めは金貨5・人手5
- 費用は着工時に払う。増築するたびに費用が倍、3倍…と上がる。収入が増えるのは最初の1回だけ
- 「急がせる」は人手2で1年早まる（1年に1回）。民心が30未満だと工事が遅れることがある
- 金貨が詰まり、人手が少し余るくらいの釣り合い。市・畑・港（金貨を生む）を早く建てるかどうかで悩む
- じっくりモードは出来事が多いので、出来事による能力の上下は半分に、事業の伸びも約半分にしている。それでも特技は増えやすいので、帝国を強め（1.3倍）、国家ランクの基準を厳しくした

### v4.1：じっくりモードを遊んだ感想と直したこと（2026-10-20）

ユーザーの感想：
- 「金貨が余る。人手が急がせる時にも使うから足りない」
- 「何もできずに一年が終わる。サクセスもそうだけど一年と言われるとちょっと勿体無さが勝つ」
- 「戦争のルールがよくわからないから詰める必要あり」

直したこと（ユーザーと合意）：
- 急がせるのは金貨2で払う（人手は建てる専用）。ユーザーは「結局金貨が足りなくなるのでは」と心配したので、**方針で金貨⇔人手を交換できる**ようにし、自動プレイでどちらも余りすぎない値にした（基本収入 金貨2・人手1）
- **今年の方針**：毎年タダで3択から1つ選ぶ。選ぶと1年が終わる（「1年を終える」ボタンの代わり）。兵を鍛える、民の声を聞く、市を見回る、国境に見張り、使者を送る、職人を雇う（金貨→人手）、出稼ぎ（人手→金貨）など。戦が近いと「演習」が必ず混ざる
- **戦のきまり**：戦の気配を0〜100のゲージで見せ、毎年どれだけ、なぜたまるかを表示。満ちると「建国N年に〇〇が攻めてくる。相手は〇〇型」と2年前に予告し、帯で残り年数を出し続ける。戦いの前に「勝てば／負ければ」を表示。勝てばゲージ0、負けると40から。帝国は25年目に予告
- 続けてユーザー：「急がせるを金貨と人手で合計2でいいんじゃない？3パターン用意して。金と人手を価値一緒にする機能として置いとく感じ」「継続的に増えるカードって金貨の方に多いよね？」→ 急がせるは 金貨2／金貨1人手1／人手2 から選ぶ形に。収入の増える事業は金貨+6・人手+2に偏っていたので、畑を人手+2に変えて金貨+4・人手+4にした
- じっくりモードの帝国は「30年かけて膨れ上がった大軍」として全体の力を1.2倍にした（伏線が多く実って特技が増えやすいため）。戦いの前に理由として表示する

### v4.3：借金と移民（2026-10-21）

ユーザー：「借金、移民受け入れをアリにしてその場で実行できることの幅を増やしたい。それによる問題も追加」「事業を一年すすめる（急がせる）を2回選べるようにしたい」
- 最初「2年進める」を「同じ方針で2年まとめて進める」と受け取ったが、ユーザーの意図は**急がせるを1年に2回押せる**ことだった（訂正済み）
- **借金**：いつでも金貨6を借りられる（同時に1つ）。5年以内に9返す。期限に返していないと「取り立ての使者」：今すぐ払う／期限を延ばす（1.5倍）／土地で払う（国力↓民心↓）／突っぱねる（戦の気配+35・悪い噂）
- **移民**：いつでも人手+3（民心−3、2年に1回）。60%で2〜3年後に「古い民と新しい民」：住む場所を分ける／祭りで交わらせる（「新しい民の技」の伏線につながる）／追い出す（人手↓・悪い噂）。3回以上受け入れると「移民の街の騒ぎ」になることがある
- 呼び名に「移民」「踏み倒し」、トロフィーに「借金の国」「人の集まる国」を追加


### v4.4：うまくいきすぎた → くじと「強い国ほど狙われる」（2026-10-21）

ユーザー：「うまくいきすぎた。秘術だけがギャンブル要素があったけど借金と移民ですごい進めやすかった」（全能力S、特技9つ、伝説の国）
- 原因：勝率を「ほぼでたらめに選ぶ自動プレイ」で合わせていた。考えて遊ぶ人はもっと勝てる。借金と移民にハズレがなかった
- 提案したA（借金・移民にくじ）＋B（強い国ほど狙われる）で合意。C（単に重くする）は楽しさが増えないので見送り
- **移民のくじ**：12% 腕のいい鍛冶屋（攻め↑）、8% 学者（禁断の研究の伏線）、12% 隣国の密偵（戦の気配+25）、8% 病（民心↓人手↓）。受け入れるほど諍いの出来事が起きやすい（40%＋10%×回数）
- **借金のくじ**：期限の年に 12% 商人組合が潰れて帳消し、20% 利息が跳ね上がって1.5倍
- **強い国ほど狙われる**：侵攻の相手はこちらとの差の80%、帝国は110%ぶん兵を増やす。能力が100で頭打ちになった分は戦場での兵の多さに回す。戦いの前の文で「評判を聞いて兵を増やしてきた」と理由を出す
- 自動プレイに「考えて遊ぶ」打ち方（`smart`）を追加。出来事と方針は試しに選んで得な方を取り、借金・移民を使い切る。決戦の勝率は smart 約56%、でたらめ 約48%

### v4.5：1年の結果を1枚ずつ（2026-10-22）

ユーザー：「一年の結果を出す時にパッと出て何が起きたかわからず次に進むことになってるので、一枚ずつ出てきてクリックすると表示みたいにしたい。自動送り、2倍速送りとかもあっていい」
- 方針を選んで1年が終わると、方針の結果・完成・予告・小さな出来事を1枚ずつ出す。カードか「次へ」をタップで次。送り方は「タップで送る／自動（1.3秒）／2倍速（0.65秒）」。自動でも最後の1枚で止まり、出来事や次の年へは自分で進む
- 出来事を選んだ結果も同じ形で1枚出す。見終わった結果は「建国N年のこと(n件)」にたたむ
- 参考に聞かれた数字：移民を2年ごとに使い切ると、問題の出来事が30年で約11回（2〜3年に1回）。控えめなら約0.7回

## 7. 別企画の備忘録：歴史もの（2026-10-18、まだ作らない）

ユーザーの発案をそのまま残す。作るときは改めて相談する。

- **歴史集め（図鑑埋め）**：「1582年 ？？？」のように年号だけ見えていて、中身が伏せてある。カード3枚（誰が／誰と／何をした、のような部品）を選択肢から選び、正解すると「本能寺の変」が開く。色集めのように全部埋めていく楽しさ
- **歴史七並べ**：トランプの4スートの代わりに地域の列（例：日本史・中国史・ヨーロッパ史・アメリカ史）。年号の隣にだけカードを置ける。手札から出していく
- 日本史・世界史は分けてもよい

条件との照らし合わせ（メモ）：
- 器は誰でも知っている（クイズ、七並べ）、入力は選ぶだけ、要素は非常に多い、図鑑埋めで一回で終わらない → 条件に合う
- 足りないもの：「戦い」と「入れた中身で結果が変わる」

戦いの形式（2026-10-18 追記）：
- **七並べで対戦は却下**。集めた年号には人によって偏りがあるので、盤面勝負は成り立ちにくい
- 戦うなら、集めたカードから**10枚選んでデッキにする**形。相性を決めて戦う
- やり方は2通り考えられる：①1枚ずつ出し合う（カイジの「Eカード」のような読み合い）、②10枚の総合力で勝負する
- 実在の出来事を扱うので、戦争・宗教・民族の扱いは事実の記述に留め、どちらかを讃える／貶める書き方はしない
