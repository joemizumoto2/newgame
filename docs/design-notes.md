# 設計メモ（2026年10月の企画会話のまとめ）

最初の企画会話で決まったこと、ユーザーの反応、却下した案、次の課題。新しいセッションはこれを前提に進める。

---

## 1. 出発点

「発明勝ちで流行るアプリを作りたい」から始まった。参考にした流行りもの：

- **WordBlade（文字ブレード）**：入力した1文字がベーゴマ風のコマになって戦う。文字の形で強さが決まり、「どの字が最強か」の研究が起きている。https://apps.apple.com/jp/app/wordblade-%E6%96%87%E5%AD%97%E3%81%A7%E6%88%A6%E3%81%86%E3%82%B3%E3%83%9E%E3%83%90%E3%83%88%E3%83%AB/id6819836440
- **80億分の1**：AI で作った人生シミュレーション。約4時間で作られ、X でバズった
- スイカゲーム、動物タワーバトル、Infinite Craft、パワプロのサクセス

ユーザーが WordBlade を評価した理由：**既にあるフォーマット（ベイブレード）に、世界共通のもの（文字）を入れて、しかも感覚的。環境が回り、やり込みが進む。**

## 2. ユーザーが大事にしている条件

1. 器は誰でも知っている遊び。独自ルールの盤面ゲームは「敷居が高い」
2. 入力は**選ぶだけ**。手書きや撮影は「技術が要って広まりにくい」
3. **ある程度客観的だけど、なんとなく分かる**ステータス。理由が読めないと盛り上がらない
4. 題材は要素が多いもの（国は属性が多いから良い。元素や誕生日は少ない）
5. 戦いがある。盛り上がる
6. 一回で終わらない。環境が回る（三すくみ）か、育てられる
7. API 代がかからない（ルールとテンプレートで作る）
8. センシティブな題材を避ける（実在の国を戦わせない）
9. 「最強の国ができたら熱い」。ダイジョーブ博士のようなギャンブル要素が欲しい
10. 無双はつまらない

## 3. 版ごとの変遷と、ユーザーの反応

### v1：国づくり → 100年の育成 → NPC と5連戦
- 反応：「イメージはかなり近い」
- 不満：
  - 8つの問いに**どのステータスが振られるか書かれているので面白みがない**
  - **100年は長い。10年の方針は曖昧すぎる**
  - **ストーリーを選択やイベントに持たせないと思い入れがない**（サクセスもそう）

### v2：初代王の治世30年、家臣4人、幼なじみの宿敵ヴァルド
- 効果を伏せた問い、王の名前、家臣の連続イベント、宿敵との決戦
- 反応：「**そういうストーリー性ではなかった。名前とかいらないかも**」
- ユーザーが欲しかったのは、用意された筋書きではなく、**選択に対してのストーリー**（80億分の1のように、自分の選択が積み重なってその国だけの物語になる）
- 物語の骨組みは `docs/story-v2.md` に残してある（v3 では使っていない）

### v3（今の版）：選択そのものが物語になる
- 名前のある登場人物をやめた。国名だけ自動で付く
- **挿絵**：「選択に対して印象づけが必要。選択する時に挿絵が出るとか」というユーザーの案。国の土地の絵に、選んだ事業の建物が増えていく。出来事ごとに場面の絵が出る
- **伏線**：選んだ事業が「種」として残り、数ターン後に出来事として返ってくる（例：港を拓く → 港の疫病 → 薬師を呼ぶ → 医術所 → 戦で兵が倒れにくい）。返ってくるとき「↩ 建国3年に港を拓いたことから」と表示
- 戦いの前に「これまでの選択が、この戦いで効く」を表示
- 結末に国の呼び名（例：「砦と港の国」）と、選択のつながりの一覧
- 反応：「**結構面白かった**」
- 字体：「タイトル以外はもう少し読みやすいフォントに。太すぎて読みづらい」→ 対応済み

## 4. いま残っている一番の課題：途中の行動の選択肢が少ない

ユーザーの言葉：「途中の行動が選択肢少ないね。やることは決まってて、行動ポイントがあってそれの中でやりくりするとかなのかな、この辺むずい」

検討した案と反応：

| 案 | 内容 | 反応 |
|---|---|---|
| 行動ポイント制 | 毎ターンのポイントで複数の行動を買う | 抽象的で国らしさが薄い（未評価） |
| 手札制（デッキ構築） | 建物から新しいカードが増える | 重い（未評価） |
| 民の割り振り | 民（人手）を決まった仕事に配る。建物が増えると配り先が増える | 提案した。ユーザーはこの後カタンの話へ |
| カタン型 | サイコロ → 土地が資源を生む → 建てる → 交易 | ユーザー：「投資したものが回収されるカタンみたいなイメージでもいいかも」→ 具体化すると「まあそれだとカタンすぎる」 |
| **投資と伏線の回収をひとつにする**（最新の提案、未回答） | 下記 | ユーザーの返事待ち |

### 最新の提案：投資の回収と伏線の回収をひとつにする

1. 毎ターン、国の収入（金貨と人手）が入る。量は建てたもので決まる（サイコロなし）
2. 事業は「植える」もの。完成まで時間がかかる。同時に複数抱えられ、限られた収入をどこに回すかで悩む。追加投資で早まり、放っておくと止まる
   - 例：港（金貨3 人手2、2ターン）→ 毎ターン金貨+2・異国の縁 ／ 北の砦（金貨2 人手3、1ターン）→ 守り↑ ／ 学舎（金貨4 人手1、3ターン）→ 人が育つ・大きな伏線 ／ 収穫祭（金貨1、すぐ）→ 民心↑
3. 完成すると、収入と物語（伏線）の両方が返ってくる。「早く効く小さな投資」か「遅いけれど大きく返る投資」か、が核
4. 出来事が投資を揺らす（災害で建設が止まる、戦の前に軍資金に回すか）

カタンとの違い：収入はサイコロでなく建てたもので決まる／回収されるのは資源と物語／完成まで年数がかかる／他プレイヤーとの交易はない。

次の一手として「事業の種類、完成までの年数・費用・返ってくるものの一覧表から詰める」ことを提案している。

## 6. 却下・保留した案（理由つき）

- コマで戦う：WordBlade の領域。ユーザー「駒は作らないよ」
- 手書き・指紋・声・虹彩：技術が要る、または一回で終わる
- ピタゴラ系：作るのが重い（簡易マイクラ）
- BGM 生成：API 代がかかる
- 実在の国で戦う：センシティブ
- 元素・誕生日：種類や属性が少ない
- 漢字ポーカー、今日の写真：悪くないが優先度が低い（別企画として保留）
- 物理演算の対戦：理想だが重い。今は2Dの押し合いアニメ

## 7. 別企画の備忘録：歴史もの（2026-10-18、まだ作らない）

ユーザーの発案をそのまま残す。作るときは改めて相談する。

- **歴史集め（図鑑埋め）**：「1582年 ？？？」のように年号だけ見えていて、中身が伏せてある。カード3枚（誰が／誰と／何をした、のような部品）を選択肢から選び、正解すると「本能寺の変」が開く。色集めのように全部埋めていく楽しさ
- **歴史七並べ**：トランプの4スートの代わりに地域の列（例：日本史・中国史・ヨーロッパ史・アメリカ史）。年号の隣にだけカードを置ける。手札から出していく
- 日本史・世界史は分けてもよい

条件との照らし合わせ（メモ）：
- 器は誰でも知っている（クイズ、七並べ）、入力は選ぶだけ、要素は非常に多い、図鑑埋めで一回で終わらない → 条件に合う
- 足りないもの：「戦い」と「入れた中身で結果が変わる」

戦いの形式（2026-10-18 追記）：
- **七並べで対戦は却下**。集めた年号には人によって偏りがあるので、盤面勝負は成り立ちにくい
- 戦うなら、集めたカードから**10枚選んでデッキにする**形。相性を決めて戦う
- やり方は2通り考えられる：①1枚ずつ出し合う（カイジの「Eカード」のような読み合い）、②10枚の総合力で勝負する

方針（2026-10-19 追記）：
- **まずは穴埋め（図鑑埋め）だけで作る**。そろえて戦うカードゲームはルール作りが難しいので、いったん保留
- **トロフィーは欲しい**（色集めのように埋めていく遊びに、節目のごほうびを付ける）
- 実在の出来事を扱うので、戦争・宗教・民族の扱いは事実の記述に留め、どちらかを讃える／貶める書き方はしない
