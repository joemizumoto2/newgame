# 建国サクセス 物語の骨組み（案）

> 中世の架空の大陸。プレイヤーは**流浪の民を率いる若き長**で、土地を見つけて**初代王**になり、約30年の治世を生きる。
> 数値は表に出さず、文章の印象で選ばせる。建国が終わったときに能力を公開し、予想との答え合わせを楽しむ。

---

## 0. 全体の流れ

```
プロローグ（故郷の滅亡と旅立ち）
  → 建国の問い（7〜8問）→ 国のかたちを公開
  → 治世30年（10ターン×約3年）
       毎ターン：事業カード3枚から1枚を選ぶ → 物語のイベント
       途中で戦いが3回（山賊討伐・隣国の侵攻・宿敵との決戦）
  → エンディング（王の称号）
  → 国カードと「〇〇王の治世」の記録
```

1回の目安は10〜15分。

---

## 1. プロローグ

> あなたの故郷、湖畔の小国リーネは、北から来た大軍に一夜で焼かれた。
> 生き延びた民を率いるのは、まだ若いあなたと、幼なじみのヴァルド。
> 冬の峠で、二人は言い争った。「遠くへ逃げ、静かに国を建てる」と言うあなた。「力を蓄え、いつか奪われたものを取り返す」と言うヴァルド。
> 翌朝、ヴァルドは半分の民を連れて、別の道へ去っていった。

- ここで**王の名前**を入力する
- ヴァルドは後の**宿敵**。最初から「同じ故郷を持つ、もう一人の王」として置く

## 2. 建国の問い（文章で選ぶ。効果は伏せる）

画面には問いと選択肢の文章だけを出す。下の表の「裏の効果」は設計用で、プレイヤーには見せない。

| # | 問い（画面の文章） | 選択肢 → 裏の効果 |
|---|---|---|
| 1 | 長い旅の果てに、あなたが足を止めた土地は | 雪をいただく山に囲まれた谷 → 山岳 ／ 潮風の吹く入り江 → 海 ／ 地平まで続く草原 → 平野 ／ 霧に包まれた島 → 島 |
| 2 | その土地で迎えた最初の冬は | 長く、骨まで凍える冬 → 寒冷 ／ 短く、穏やかな冬 → 温暖 ／ 乾いた風が吹きやまない → 乾燥 ／ 冬と呼べる季節がない → 熱帯 |
| 3 | 民が最初の冬を越すために頼ったのは | 山肌に見つけた鉄 → 鉱物 ／ 皆で拓いた小さな畑 → 農作物 ／ 海と川の魚 → 漁業 ／ 旅の間に磨いた職人の技 → 技術 |
| 4 | あなたについてきた民は | わずかだが、旅で鍛えられた者たち → 少数精鋭 ／ 百ほどの家族 → 中規模 ／ 道中で膨れ上がった大集団 → 超大国 |
| 5 | 子どもたちに、まず何を教えるか | 星と数の読み方 → 理系 ／ 文字と言葉 → 文系 ／ 歌と物語 → 芸術 ／ 剣と馬 → 体育 |
| 6 | 王として、民に求める貢ぎは | 今は何も求めない → 軽い ／ 収穫の一割 → 普通 ／ 収穫の三割 → 重い |
| 7 | 民が囲む夕餉は | 麦の粥 → 蓄え（国力・守備） ／ 固い黒パン → 遠征向き（攻撃・機動） ／ 干し肉 → 力がつく（攻撃） ／ 魚の塩漬け → 身軽（機動） |
| 8 | 王冠の内側に刻む言葉は | 「誰もが自由に」→ 自由 ／ 「和をもって」→ 調和 ／ 「恐れず挑め」→ 挑戦 ／ 「祖先に恥じぬよう」→ 伝統 |

**公開の場面**

> 国のかたちが決まった。
> 「雪の谷のノルヴァ王国。冬に強く、守りに優れる。ただし、外へ攻め出るのは苦手だ」

- 能力のランク、性格（守り・物量・機動）、国旗をここで初めて見せる
- 一文の評は、上位2つの能力と弱点から自動で作る

## 3. 治世（10ターン、1ターン＝約3年）

### 1ターンの流れ

1. **事業カード**が3枚配られ、1枚を選ぶ
2. 物語のイベントが起きる（家臣・宿敵・出来事のどれか）
3. 年表に1行が記される（例：「即位6年　北の砦が完成した」）

能力の伸びは数値で出さず、言葉で伝える（「守りが少し固まった」「民の顔が曇った」）。能力表そのものは画面に出しておく。

### 事業カード（例）

国の地形や資源に合ったカードが出やすい。家臣が仲間になると専用のカードが増える。

| カード | 主に伸びる | 出やすい国 |
|---|---|---|
| 北の砦を築く | 守備 | 山岳・寒冷 |
| 城壁を石で固める | 守備 | どこでも |
| 港町を拓く | 機動 | 海・島・漁業 |
| 街道を敷く | 機動 | 平野・乾燥 |
| 騎士団を設ける | 攻撃 | 体育・平野 |
| 鍛冶の村を興す | 攻撃 | 鉱物・山岳 |
| 森を拓いて畑にする | 国力 | 農作物・温暖 |
| 水車を建てる | 国力 | 技術・理系 |
| 市を開く | 国力・機動 | 自由・漁業 |
| 収穫祭を催す | 民心 | どこでも |
| 学舎を建てる | 民心・家臣の成長 | 文系・芸術 |
| （エリオ加入後）兵を鍛える | 攻撃・エリオの物語が進む | — |
| （ジル加入後）異国と商う | 国力・機動・ジルの物語が進む | — |

- 同じ系統を続けると伸びが増えるが、民心が減りやすい（続けるか切り替えるかで悩ませる）
- 民心が低いと、カードの事業が失敗することがある

## 4. 家臣（パワプロの仲間に相当）

4人。全員とは深く付き合えない（ターンが足りない）ので、**誰の物語を追うか**で国の育ち方が変わる。各人の物語は3段階で、最後まで進むと金の特技が手に入る。

### エリオ（若き剣士）→ 金特「名将」

1. **狼を斬った若者**（1〜3ターン目）
   村を襲った狼の群れを、一人で斬り伏せた若者が仕官を願い出た。
   - 召し抱える → 仲間になる
   - 見送る → 物語はここで終わる
2. **命令違反の初陣**（4〜6ターン目、山賊討伐の後）
   エリオは命令を無視して突撃し、勝った。だが部下を三人失った。
   - 厳しく叱る → 冷静な将に育つ（守備・機動が伸びる道へ）
   - 勇気をたたえる → 猛将に育つ（攻撃が大きく伸びる道へ）
3. **しんがり**（7〜9ターン目、隣国の侵攻の後）
   撤退する味方を逃がすため、エリオが最後尾に残ると言う。
   - 任せる → 生きて戻れば金特「名将」（冷静な将）／青特「突撃」＋攻撃大幅上昇（猛将）
   - 止める → 彼は不満を抱えたまま残る（特技なし）

### マルタ（老いた宰相）→ 金特「黄金期」

1. **旅の老女**（1〜3ターン目）
   道端で倒れていた老女は、実は滅んだ故郷リーネの宰相だった。
   - 城に迎える → 仲間になる
2. **税の改革**（4〜6ターン目）
   「数年は民に恨まれます。ですが十年後、この国は豊かになる」
   - 改革を許す → 一時的に民心が下がり、後で国力が大きく伸びる
   - 退ける → マルタは黙って引き下がる（物語が止まる）
3. **ヴァルドからの誘い**（7〜9ターン目）
   宿敵ヴァルドが、マルタを高い位で引き抜こうとしているという噂が立つ。
   - 信じる → 金特「黄金期」。マルタは誘いの手紙を王の前で焼く
   - 疑って遠ざける → マルタは国を去る。赤特「猜疑」（家臣の物語が進みにくくなる）

### ジル（借金まみれの商人）→ 青特「海洋国家」または「外交上手」

1. **転がり込んだ男**（1〜4ターン目）
   借金取りに追われた商人が、城門に駆け込んできた。
   - 借金を肩代わりする → 国力が下がるが、仲間になる
   - 追い返す → 物語はここで終わる
2. **異国の地図**（4〜7ターン目）
   ジルが、海の向こうの国々を描いた地図を持ち帰った。
   - 港を開く → 青特「海洋国家」へ近づく
   - 陸の道を開く → 青特「外交上手」へ近づく
3. **密貿易**（7〜9ターン目）
   ジルがヴァルドの国とひそかに取引していたことが分かった。
   - 許す → 特技を得る。さらにヴァルドの国の内情が分かる（決戦で奇襲が使える）
   - 罰する → ジルは去る。民心は上がる

### ノーラ（変わり者の学者）→ 「禁断の秘術」（ダイジョーブ博士枠）

1. **星読みの娘**（1〜4ターン目）
   毎晩、塔に登って星を記録している娘がいる。「来年、川があふれます」
   - 話を聞く → 仲間になる。次の災害を予言してくれる
2. **奇妙な発明**（4〜7ターン目）
   ノーラが、水車と投石機の図面を持ってきた。
   - 水車を作らせる → 国力が伸びる
   - 投石機を作らせる → 攻撃が伸びる
3. **禁断の秘術**（8ターン目）
   「国そのものを作り変える方法を見つけました。ただ、何が起きるかは私にも分かりません」
   - 試させる → 大成功（金特「覚醒」）／成功／失敗／暴走（赤特「暴走」）
   - やめさせる → ノーラは少し寂しそうに笑う

ノーラを仲間にしていない場合も、8ターン目に「異国の錬金術師」として同じ選択が一度だけ出る（成功率は低め）。

## 5. 宿敵ヴァルド（パワプロのライバルに相当）

同じ故郷を持つ、もう一人の王。あなたの選択で**友好度**が上下し、決戦の形と結末が変わる。ヴァルドの国も裏で同じように育ち、能力は決戦で初めて全部見える。

1. **便り**（2ターン目）
   ヴァルドが東の土地に国を建てたと、旅人が伝えてきた。
   - 祝いの使者を送る → 友好度＋
   - 何もしない → 変化なし
   - 国境に兵を置く → 友好度−、守備＋
2. **国境の村**（5ターン目）
   二つの国の間にある村が、どちらにつくかで割れている。
   - 村人に選ばせる → 友好度＋、結果は運次第
   - ヴァルドに譲る → 友好度＋＋、民心−
   - 兵を出して押さえる → 友好度−−、ここで小さな戦いになる
3. **飢饉**（8ターン目）
   ヴァルドの国が飢饉に襲われ、食料を求めてきた。
   - 蔵を開いて助ける → 友好度＋＋、国力−
   - 断る → 友好度−
   - 弱った今こそ攻める → 友好度は最低に。悪名
4. **決戦**（10ターン目）
   北の大軍が再び大陸に現れる。ヴァルドは「この大陸を一つにしなければ、また故郷と同じことになる」と言う。
   - 友好度が高い → 「どちらが王にふさわしいか、一度だけ戦って決めよう」（一騎打ち形式。負けても国は滅びない）
   - 友好度が低い → 総力戦。負ければ国は飲み込まれる

## 6. 治世の中の戦い

戦いは治世の中に3回だけ置く（すべて自動観戦。作戦は1つ選ぶ）。

| 時期 | 相手 | 役割 |
|---|---|---|
| 3〜4ターン目 | 山賊団 | 練習試合。負けても小さな損で済む |
| 6〜7ターン目 | 隣国の侵攻（ヴァルドとは別の国） | 中盤の山場。負けると民心と国力が下がる |
| 10ターン目 | 宿敵ヴァルド | 決戦。結末に直結する |

治世の後は、国カードを使って**友達の国と戦える**ようにする（次の段階）。

## 7. エンディング（王の称号）

選択の積み重ねで決まる。国カードと記録に残る。

| 称号 | 主な条件 |
|---|---|
| 名君 | 民心を高く保ち、決戦に勝つ |
| 覇王 | 攻撃が高く、総力戦でヴァルドを下す |
| 賢王 | マルタかノーラの物語を最後まで進める |
| 和平の王 | 友好度が高く、一騎打ちのあと大陸を共に治める |
| 暴君 | 民心が低い、または悪名を得ている |
| 悲運の王 | 決戦に敗れる |
| 伝説の王 | すべての能力がA以上、金特2つ以上、決戦に勝つ |

結びの一文の例：
> ノルヴァ王国初代王エルン、治世31年。雪の谷に生まれた小さな国は、宿敵と手を取り、大陸の盾となった。人々は彼を「和平の王」と呼んだ。

## 8. 開発メモ

- **数値の隠し方**：建国の問いは効果を完全に伏せる。治世中は能力表を見せ、事業カードとイベントの効果は「守りが少し固まりそう」のような言葉で示す
- **文章の量**：家臣4人×3段階＋宿敵4段階＋出来事15本ほど。テンプレートの組み合わせで作れるので、API は不要
- **繰り返し遊ぶ理由**：誰の物語を追うか、宿敵とどう向き合うかで結末が変わる。称号を集める図鑑を作る
- **今の試作から引き継ぐもの**：4つの能力、三すくみ、特技、戦闘の計算、観戦画面
