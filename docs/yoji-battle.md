# 四文字熟語バトル 企画メモ

README の式「既に遊び方が知られた器 × 誰でも持っている入力 × 入れた中身で結果が変わる」に当てはめた案。器は札の出し合い（3本勝負）、入力は熟語の札を選ぶだけ、中身は熟語の画数・部首・意味。

試作: `yoji/index.html`（CPU 対戦）

## ルール（試作の版）

- 熟語の札を5枚ずつ配る。3本勝負で3枚使い、2枚は余る
- 対局の最初に三本の基準をまとめて発表する。一本目・二本目（各1点）は下の表からランダム、三本目（2点）は「総合力・三すくみ」
- 一本ごとに15秒以内で1枚出す。時間切れは自動で出る
- 相手の札は型（攻・守・策）だけ見える
- 同点は総合力で判定。合計2対2は引き分け

## 一本目・二本目の基準

データから計算できるものだけにして、勝ち負けの理由が誰でも確かめられるようにする。

| 基準 | 比べるもの |
|---|---|
| 画数が多い／少ない | 4字の画数の合計 |
| 同じ部首が多い | 同じ部首の字の数（魑魅魍魎は鬼が4字） |
| 数字が大きい | 熟語の中の数字の合計（千差万別＝11000） |
| 読みが長い | 読みの音の数。小さい「ゃゅょ」は数えない |
| 一字の画数 | いちばん画数の多い一字 |

## 三本目：総合力と三すくみ

- 総合力＝画数の合計＋（同じ部首の字の数−1）×5
- 型は熟語の意味で決める。守は攻を受け止め、攻は策を押し切り、策は守を崩す
- 相性が有利なら総合力×1.5
- 画数の多い札は三本目でも強いので、一本目の「画数が多い」で使うか残すかで迷う

## データ

- `yoji/idioms.tsv` … 熟語・読み・型・意味（80語）
- `yoji/build.py` … 画数（日本の字形）と部首を Unihan から計算し、`index.html` に書き込む
