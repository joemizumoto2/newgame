# 建国サクセス（プロトタイプ）

中世の架空の大陸で国を建て、30年かけて育てるブラウザゲームの試作。選んだことが国の挿絵に残り、何年か後に出来事として返ってくる。

遊べるページ: https://claude.ai/artifact/SBiQpEYof3u7KPHrs6X6qK

- `index.html` … Artifact 用のページ本体（`<!doctype>` などの外枠は公開時に付く）
- `CLAUDE.md` … Claude Code のセッションが最初に読む、作業の前提
- `docs/design-notes.md` … 企画会話のまとめ（ユーザーの反応、却下した案、次の課題）
- `docs/story-v2.md` … v2（王と家臣の版）の物語の骨組み。v3 では使っていない
- `tools/balance.js` … 自動プレイで勝率などを確かめる（`node tools/balance.js 2000`）
- `tools/smoke.js` … ブラウザで最初から結末まで通す（Playwright）

## 版

- v1：8問（効果を表示）→ 100年・10期の育成 → NPC と5連戦
- v2：プロローグ → 8問（効果は伏せ、建国時に公開）→ 初代王の治世30年（事業カード、家臣4人の物語、宿敵ヴァルド）→ 治世中の3戦 → 王の称号
- v3：名前のある登場人物をやめ、選択そのものを物語にした。8問（効果は伏せる）→ 建国30年（事業カード。建てたものが国の挿絵に増え、数年後に伏線として出来事が返ってくる）→ 3戦（過去の選択が効く）→ 国の呼び名と「選択のつながり」

## コンセプト

WordBlade（文字がコマになって戦う）、スイカゲーム、動物タワーバトルの型を分解して得た式で作る。

> 既に遊び方が知られた器 × 誰でも持っている入力 × 入れた中身で結果が変わる

### 守る条件

1. 器は誰でも知っている遊び（押し合い、陣取り、じゃんけんの延長）
2. 入力は**選ぶだけ**（手書き・撮影は重い）
3. 選んだものの性質が結果に効き、**理由が読める**（ある程度客観的で、なんとなく分かる）
4. 要素が多い題材（国のように属性が多いもの）
5. 戦いがある
6. 一回で終わらず、環境が回る
7. API 代がかからない（ルールとテンプレートで作る）
8. センシティブな題材を避ける（実在の国は使わない）

## 全体の構造

```
国づくり → 建国サクセス → 共有マップに建国 → 隣国と戦う → 領土が動く → 覇権・崩壊 → 新時代
```

| 層 | 内容 | v1 |
|---|---|---|
| ① 国づくり | 8問（気候、地形、資源、人口、教育、税、食文化、モットー）。選択肢ごとに効果と理由を表示 | ○ |
| ② 建国サクセス | パワプロのサクセス型の短期育成。10期×方針選択＋イベント分岐で、ステータスと特技を得る | ○ |
| ③ 禁断の秘術 | 第8期のギャンブル（ダイジョーブ博士枠）。大成功・成功・失敗・暴走 | ○ |
| ④ 戦い | 自動観戦。三すくみの性格（守り・物量・機動）、4ステータス、戦場の地形、特技、作戦で決まる | ○（NPCと5連戦） |
| ⑤ 共有マップ | 六角形の区画の陣取り。攻撃は隣接する国にだけ。勝てば区画を奪い、負ければ失う | × |
| ⑥ 覇権サイクル | 世界制覇した国も一定期間で崩壊・分裂。挑戦者に討伐ボーナス | × |
| ⑦ 記録と共有 | 年表、国カード、歴史地図のタイムラプス | 年表と国カードのみ |

### 設計の考え方

- ステータスは4つ（攻撃・守備・機動・国力）＋民心（パワプロの体力に相当）。隠し乱数で強さを決めない
- 三すくみ：守り型は機動型に強い、機動型は物量型に強い、物量型は守り型に強い
- 特技は育成中の選択履歴で身につく（青＝通常、金＝強力、赤＝弱点）
- 無双は構造で防ぐ：広い国ほど国境が長い、攻撃回数の上限、首都は奪えない、帝国の期限と崩壊
